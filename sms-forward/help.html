Getting Started

🚀 Getting Started

How SMS Forward Works

SMS Forward automatically captures incoming SMS messages and forwards them to your configured destinations — Email, Telegram, Discord, or custom Webhooks.

  1. Set up at least one SMTP email configuration
  2. Create a forwarding target (where to send)
  3. Create a filter rule (which SMS to forward)
  4. Grant SMS and notification permissions
  5. Enable the forwarding service

Filter Rules

🔍 Filter Rules

How Filter Matching Works

Each filter rule has a sender filter and content filter. Both are optional:

  • Both empty — matches ALL incoming SMS
  • Sender filter only — matches SMS from specific sender
  • Content filter only — matches SMS containing specific text
  • Both set — both conditions must match (AND logic)
💡 Tip: Matching is case-insensitive and supports Turkish characters (İ/i, Ş/ş, Ğ/ğ). With contacts permission, you can also filter by contact name.

Regex Filtering PRO

Pro users can enable regex for advanced pattern matching. Examples:

  • ^\+90 — Turkish numbers only
  • OTP|verification|code — OTP messages
  • \d{6} — Messages containing 6-digit codes

Battery

🔋 Battery & Background Service

Keeping SMS Forward Running

Android aggressively kills background apps to save battery. To ensure SMS Forward works reliably:

  1. Go to Settings → Battery Optimization and disable optimization for SMS Forward
  2. On Xiaomi/MIUI: Settings → Apps → Manage apps → SMS Forward → Autostart: ON
  3. On Huawei/EMUI: Settings → Battery → App launch → SMS Forward → Manage manually → Enable all
  4. On Samsung: Settings → Battery → Battery usage → Sleeping apps → Remove SMS Forward
⚠️ Important: After a device restart, the app's boot receiver will automatically restart the forwarding service if it was enabled.
Troubleshooting

🔧 Troubleshooting

SMS is not being forwarded

  • Check that the forwarding service is ON (toggle on home screen)
  • Verify SMS permission is granted in Settings → Permissions
  • Ensure battery optimization is disabled for the app
  • Check that your filter rule is active and has at least one forwarding target
  • Review Debug Logs (Settings → Debug Logs) for detailed error info

Email sending fails

  • Verify your SMTP credentials — use an App Password, not your regular password
  • Check SMTP host and port are correct
  • Try sending a test email from the forwarding target screen
  • For Gmail: ensure "Less secure apps" or App Passwords are configured

Telegram messages not arriving

  • Make sure you started the bot (sent /start or any message)
  • Verify the Bot Token and Chat ID are correct
  • Try the test button on the Telegram forwarding target screen

Filterregeln

🔍 Filterregeln

So funktioniert der Filterabgleich

Jede Filterregel hat eine Absenderfilter Und Inhaltsfilter. Beides ist optional:

  • Beide leer – entspricht ALLEN eingehenden SMS
  • Nur Absenderfilter – Entspricht SMS von einem bestimmten Absender
  • Nur Inhaltsfilter – Entspricht SMS, die einen bestimmten Text enthalten
  • Beide eingestellt — beide Bedingungen müssen übereinstimmen (UND-Logik)
💡 Tipp: Bei der Zuordnung wird die Groß-/Kleinschreibung nicht beachtet und türkische Zeichen (İ/i, Ş/ş, Ğ/ğ) unterstützt. Mit der Kontaktberechtigung können Sie auch nach Kontaktnamen filtern.

Regex-Filterung PRO

Pro-Benutzer können Regex für den erweiterten Mustervergleich aktivieren. Beispiele:

  • ^\+90 — Nur türkische Nummern
  • OTP|verification|code — OTP-Nachrichten
  • \d{6} — Nachrichten mit 6-stelligen Codes

Batterie

🔋 Batterie- und Hintergrundservice

Die SMS-Weiterleitung läuft weiter

Android beendet aggressiv Hintergrund-Apps, um Batterie zu sparen. Um sicherzustellen, dass die SMS-Weiterleitung zuverlässig funktioniert:

  1. Gehe zu Einstellungen → Batterieoptimierung und deaktivieren Sie die Optimierung für die SMS-Weiterleitung
  2. An Xiaomi/MIUI: Einstellungen → Apps → Apps verwalten → SMS-Weiterleitung → Autostart: EIN
  3. An Huawei/EMUI: Einstellungen → Akku → App-Start → SMS-Weiterleitung → Manuell verwalten → Alle aktivieren
  4. An Samsung: Einstellungen → Akku → Akkuverbrauch → Schlafende Apps → SMS-Weiterleitung entfernen
⚠️ Wichtig: Nach einem Geräteneustart startet der Boot-Receiver der App den Weiterleitungsdienst automatisch neu, sofern dieser aktiviert war.
Fehlerbehebung

🔧 Fehlerbehebung

SMS wird nicht weitergeleitet

  • Überprüfen Sie, ob der Weiterleitungsdienst vorhanden ist AN (auf dem Startbildschirm umschalten)
  • Überprüfen Sie, ob die SMS-Berechtigung erteilt wurde Einstellungen → Berechtigungen
  • Stellen Sie sicher, dass die Batterieoptimierung für die App deaktiviert ist
  • Überprüfen Sie, ob Ihre Filterregel lautet aktiv und hat mindestens ein Weiterleitungsziel
  • Rezension Debug-Protokolle (Einstellungen → Debug-Protokolle) für detaillierte Fehlerinformationen

Der E-Mail-Versand schlägt fehl

  • Überprüfen Sie Ihre SMTP-Anmeldeinformationen – verwenden Sie eine App-Passwort, nicht Ihr reguläres Passwort
  • Überprüfen Sie, ob SMTP-Host und -Port korrekt sind
  • Versuchen Sie, eine Test-E-Mail über den Weiterleitungszielbildschirm zu senden
  • Für Gmail: Stellen Sie sicher, dass „Weniger sichere Apps“ oder App-Passwörter konfiguriert sind

Telegram-Nachrichten kommen nicht an

  • Stellen Sie sicher, dass Sie begonnen der Bot (gesendet /start oder eine beliebige Nachricht)
  • Überprüfen Sie, ob das Bot-Token und die Chat-ID korrekt sind
  • Probieren Sie die Testschaltfläche auf dem Zielbildschirm für die Telegram-Weiterleitung aus

फ़िल्टर मिलान कैसे काम करता है

प्रत्येक फ़िल्टर नियम में एक है प्रेषक फ़िल्टर और सामग्री फ़िल्टर. दोनों वैकल्पिक हैं:

  • केवल प्रेषक फ़िल्टर - विशिष्ट प्रेषक के एसएमएस से मेल खाता है
  • केवल सामग्री फ़िल्टर - विशिष्ट पाठ वाले एसएमएस से मेल खाता है
  • दोनों सेट - दोनों स्थितियाँ मेल खानी चाहिए (और तर्क)
💡टिप: मिलान केस-असंवेदनशील है और तुर्की वर्णों (İ/i, Ş/ş, Ğ/ğ) का समर्थन करता है। संपर्क अनुमति के साथ, आप संपर्क नाम से भी फ़िल्टर कर सकते हैं।

Как работает СМС переадресация

SMS Forward автоматически перехватывает входящие SMS-сообщения и пересылает их в настроенные вами пункты назначения — электронную почту, Telegram, Discord или пользовательские веб-перехватчики.

  1. Установите хотя бы один Настройка электронной почты SMTP
  2. Создайте цель пересылки (куда отправить)
  3. Создайте правило фильтра (какое СМС пересылать)
  4. Грант Разрешения на SMS и уведомления
  5. Включите экспедиторская служба

Правила фильтра

🔍 Правила фильтра

Как работает сопоставление фильтров

Каждое правило фильтра имеет фильтр отправителя и фильтр контента. Оба являются необязательными:

  • Оба пусты — соответствует ВСЕМ входящим SMS
  • Только фильтр отправителей — соответствует SMS от конкретного отправителя
  • Только фильтр контента — соответствует SMS, содержащему определенный текст
  • Оба набора — оба условия должны совпадать (логика И)
💡Совет: Сопоставление не учитывает регистр и поддерживает турецкие символы (İ/i, Ş/ş, Ğ/ğ). Если у вас есть разрешение на контакты, вы также можете фильтровать по имени контакта.

Фильтрация регулярных выражений PRO

Пользователи Pro могут включить регулярное выражение для расширенного сопоставления с образцом. Примеры:

  • ^\+90 — Только турецкие номера
  • OTP|verification|code — OTP-сообщения
  • \d{6} — Сообщения, содержащие 6-значные коды

  • Убедитесь, что токен бота и идентификатор чата верны.

Aturan Penyaringan

🔍 Aturan Penyaringan

Cara Kerja Pencocokan Filter

Setiap aturan filter memiliki a filter pengirim Dan penyaring konten. Keduanya opsional:

  • Keduanya kosong — cocok dengan SEMUA SMS yang masuk
  • Filter pengirim saja — mencocokkan SMS dari pengirim tertentu

  • Keduanya siap — kedua kondisi harus cocok (DAN logika)
💡 Kiat: Pencocokan tidak peka huruf besar-kecil dan mendukung karakter Turki (İ/i, Ş/ş, Ğ/ğ). Dengan izin kontak, Anda juga dapat memfilter berdasarkan nama kontak.

Android secara agresif mematikan aplikasi latar belakang untuk menghemat baterai. Untuk memastikan SMS Forward berfungsi dengan andal:

Pesan Telegram tidak sampai

  • Coba tombol tes pada layar target penerusan Telegram

জেনেরিক HTTP ওয়েবহুক

ওয়েবহুক আপনার নিয়মের সাথে মেলে যখনই কোনো SMS আপনার নির্দিষ্ট করা কোনো URL-এ একটি HTTP POST (বা PUT/PATCH) অনুরোধ পাঠায়। এটি এর সাথে সংহত করার জন্য উপযুক্ত:

  • জাপিয়ার - একটি "ক্যাচ হুক" ট্রিগার ব্যবহার করুন
  • আইএফটিটিটি - একটি ওয়েবহুক ট্রিগার ব্যবহার করুন
  • n8n/ মেক - একটি ওয়েবহুক নোড ব্যবহার করুন
  • কাস্টম API - আপনার নিজস্ব সার্ভার শেষ পয়েন্ট

বডি টেমপ্লেট প্লেসহোল্ডার

আপনার JSON বডি টেমপ্লেটে এই স্থানধারকগুলি ব্যবহার করুন:

  • {sender} - ফোন নম্বর বা প্রেরকের আইডি
  • {contactName} - যোগাযোগের নাম (যদি অনুমতি দেওয়া হয়)
  • {body} — SMS পাঠ্য বিষয়বস্তু
  • {date} — ISO 8601 টাইমস্ট্যাম্প
  • {ruleName} - মিলে যাওয়া নিয়মের নাম

ব্যাটারি

🔋 ব্যাটারি এবং পটভূমি পরিষেবা

এসএমএস ফরওয়ার্ড চালু রাখা

ব্যাটারি বাঁচাতে অ্যান্ড্রয়েড আক্রমনাত্মকভাবে ব্যাকগ্রাউন্ড অ্যাপসকে মেরে ফেলে। নিশ্চিত করতে এসএমএস ফরওয়ার্ড নির্ভরযোগ্যভাবে কাজ করে:

  1. যান সেটিংস → ব্যাটারি অপ্টিমাইজেশান৷ এবং এসএমএস ফরওয়ার্ডের জন্য অপ্টিমাইজেশন অক্ষম করুন
  2. চালু Xiaomi/MIUI: সেটিংস → অ্যাপস → অ্যাপ পরিচালনা করুন → এসএমএস ফরওয়ার্ড → অটোস্টার্ট: চালু
  3. চালু Huawei/EMUI: সেটিংস → ব্যাটারি → অ্যাপ লঞ্চ → এসএমএস ফরওয়ার্ড → ম্যানুয়ালি পরিচালনা করুন → সমস্ত সক্ষম করুন
  4. চালু স্যামসাং: সেটিংস → ব্যাটারি → ব্যাটারি ব্যবহার → স্লিপিং অ্যাপস → এসএমএস ফরওয়ার্ড সরান
⚠️ গুরুত্বপূর্ণ: একটি ডিভাইস পুনঃসূচনা করার পরে, অ্যাপটির বুট রিসিভার স্বয়ংক্রিয়ভাবে ফরওয়ার্ডিং পরিষেবাটি সক্ষম হলে পুনরায় চালু করবে।
সমস্যা সমাধান

🔧 সমস্যা সমাধান

এসএমএস ফরওয়ার্ড করা হচ্ছে না

  • ফরোয়ার্ডিং পরিষেবাটি পরীক্ষা করুন চালু (হোম স্ক্রিনে টগল করুন)
  • যাচাই করুন এসএমএস অনুমতি দেওয়া হয়েছে সেটিংস → অনুমতি
  • অ্যাপের জন্য ব্যাটারি অপ্টিমাইজেশন অক্ষম করা আছে তা নিশ্চিত করুন
  • আপনার ফিল্টার নিয়ম চেক করুন সক্রিয় এবং অন্তত একটি ফরওয়ার্ডিং লক্ষ্য আছে
  • পর্যালোচনা ডিবাগ লগ বিশদ ত্রুটির তথ্যের জন্য (সেটিংস → ডিবাগ লগ)

ইমেল পাঠানো ব্যর্থ হয়েছে

  • আপনার SMTP শংসাপত্র যাচাই করুন — একটি ব্যবহার করুন অ্যাপ পাসওয়ার্ড, আপনার নিয়মিত পাসওয়ার্ড নয়
  • চেক করুন SMTP হোস্ট এবং পোর্ট সঠিক
  • ফরওয়ার্ডিং টার্গেট স্ক্রীন থেকে একটি পরীক্ষার ইমেল পাঠানোর চেষ্টা করুন
  • Gmail এর জন্য: নিশ্চিত করুন "কম সুরক্ষিত অ্যাপ" বা অ্যাপ পাসওয়ার্ড কনফিগার করা আছে

টেলিগ্রাম বার্তা আসছে না

  • আপনি নিশ্চিত করুন শুরু বট (প্রেরিত/শুরু বা কোনো বার্তা)
  • বট টোকেন এবং চ্যাট আইডি সঠিক কিনা তা যাচাই করুন
  • টেলিগ্রাম ফরওয়ার্ডিং টার্গেট স্ক্রিনে পরীক্ষা বোতামটি ব্যবহার করে দেখুন

عام HTTP ویب ہُک

ویب ہکس HTTP POST (یا PUT/PATCH) کی درخواست بھیجتے ہیں کسی بھی URL پر جو آپ بیان کرتے ہیں جب بھی کوئی SMS آپ کے اصول سے میل کھاتا ہے۔ یہ اس کے ساتھ ضم کرنے کے لیے بہترین ہے:

  • زپیئر - ایک "کیچ ہک" ٹرگر استعمال کریں۔
  • آئی ایف ٹی ٹی ٹی - ویب ہکس ٹرگر استعمال کریں۔
  • n8n / بنائیں - ایک ویب ہک نوڈ استعمال کریں۔
  • حسب ضرورت API - آپ کا اپنا سرور اینڈ پوائنٹ

باڈی ٹیمپلیٹ پلیس ہولڈرز

اپنے JSON باڈی ٹیمپلیٹ میں ان پلیس ہولڈرز کا استعمال کریں:

  • {sender} - فون نمبر یا بھیجنے والے کی شناخت
  • {contactName} - رابطہ کا نام (اگر اجازت دی گئی ہو)
  • {body} - ایس ایم ایس ٹیکسٹ مواد
  • {date} - ISO 8601 ٹائم اسٹیمپ
  • {ruleName} - مماثل اصول کا نام

🔍 فلٹر رولز

فلٹر میچنگ کیسے کام کرتی ہے۔

ہر فلٹر اصول میں ایک ہوتا ہے۔ بھیجنے والا فلٹر اور مواد فلٹر. دونوں اختیاری ہیں:

  • دونوں خالی - تمام آنے والے SMS سے میل کھاتا ہے۔
  • صرف بھیجنے والا فلٹر - مخصوص بھیجنے والے کے ایس ایم ایس سے میل کھاتا ہے۔
  • صرف مواد کا فلٹر - مخصوص متن پر مشتمل SMS سے میل کھاتا ہے۔
  • دونوں سیٹ - دونوں شرائط مماثل ہونی چاہئیں (اور منطق)
💡 مشورہ: مماثلت کیس کے لحاظ سے غیر حساس ہے اور ترکی حروف (İ/i، Ş/ş، Ğ/ğ) کو سپورٹ کرتی ہے۔ رابطوں کی اجازت کے ساتھ، آپ رابطے کے نام سے بھی فلٹر کر سکتے ہیں۔
